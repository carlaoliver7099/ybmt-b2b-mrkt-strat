## 🎯 About This Repo

This repository contains the complete marketing launch kit for **YBMT Pool Decks**, a specialist pool deck division of *Your Building & Maintenance Team* (YBMT) serving Brisbane, Gold Coast and Sunshine Coast. Assets were professionally developed to support a 30-day launch sequence targeting an estimated **$315K–$525K pipeline in the first 90 days**.

Every asset in this repo follows a consistent brand system (navy + timber + pool aqua palette, Fraunces + Inter typography) and is designed to work together as an integrated marketing engine — from first ad impression through to closed project.

The kit is intended for use by YBMT directors, their web developer, marketing collaborators, and approved partners. It is **not open-source** — see [License](#-license) below.

## 🚀 Quick Start

### How to Download Each Asset Type

1. **Images (PNG)** — Right-click → *"Save Image As..."* → save to local folder
2. **HTML Documents** — Open link → Print → *"Save as PDF"* → download
3. **Slide Decks** — Open the agent link → look for *"Export to PPTX"* or *"Export to PDF"* button
4. **Videos (MP4)** — Right-click video → *"Save Video As..."* OR use the download icon
5. **Logo** — Right-click → Save as PNG (transparent background)

### Bulk Download Script (Optional)

Save the following as `download-assets.sh`, then run `chmod +x download-assets.sh && ./download-assets.sh`:

## ✅ Launch Deployment Checklist

Use this 30-day checklist directly in GitHub Issues, Notion, or printed on your office wall.

### Week 1: Foundation

- [ ] Review all 18 marketing assets
- [ ] Email website copy + landing page to developer
- [ ] Print 250 brochures at Officeworks
- [ ] Set up Google Business Profile (Brisbane)
- [ ] Set up Google Business Profile (Gold Coast)
- [ ] Set up Google Business Profile (Sunshine Coast)
- [ ] Fix typo on ybmt.com.au/decks-built page
- [ ] Add "Pool Decks" to main navigation

### Week 2: Go-to-Market

- [ ] Pick up printed brochures
- [ ] Visit 5 real estate offices
- [ ] Set up Mailchimp + 5-email nurture sequence
- [ ] Schedule first 5 Instagram posts
- [ ] Visit 5 pool shops/showrooms
- [ ] Brochure drop in one affluent suburb

### Week 3: Activate Paid + Organic

- [ ] Open Meta Ads Manager account
- [ ] Launch 3 Meta ads ($75/day each, 7-day test)
- [ ] Publish Blog Post 1 (Brisbane Pool Deck Cost)
- [ ] Post Instagram Post 1
- [ ] Monitor Meta Ads Cost Per Lead daily
- [ ] Visit 3 more real estate offices

### Week 4: Optimize + Refer

- [ ] Kill underperforming Meta ads, scale winner
- [ ] Build 30-partner target hit list
- [ ] Email 10 architects with Referral Partner Kit
- [ ] Publish Blog Post 2 (Composite vs Hardwood)
- [ ] Post Instagram Post 4
- [ ] Refill real estate office brochures
- [ ] Follow up unconverted leads
- [ ] Review 30-day metrics & plan next 30 days

## 🎨 Brand Guidelines

### Color Palette (Hex Codes)

```css
--navy-primary:   #1B3A5C;   /* Trust, premium */
--timber-warm:    #B8743D;   /* Decking warmth */
--aqua-pool:      #4DB6C7;   /* Water/freshness */
--cream-bg:       #F5F1EA;   /* Off-white background */
--charcoal-text:  #2B2B2B;   /* Body text */
--coral-accent:   #D85A4A;   /* Partnership CTAs */
--green-accent:   #5FB369;   /* Sales CTAs */
```

### Typography Stack

```css
/* Display headings */
font-family: 'Fraunces', serif;
font-style: italic;
font-weight: 600;

/* Body text & UI */
font-family: 'Inter', sans-serif;
font-weight: 400;
```

### Voice & Tone

- **Premium but approachable** — not stuffy or corporate
- **Specialist authority** — we own the pool deck niche
- **Trust-first** — QBCC, compliance, warranty mentioned prominently
- **Local-flavored** — references to SEQ suburbs, lifestyle, climate
